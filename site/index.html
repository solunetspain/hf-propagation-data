Documentación

      
Esta sección explica qué muestra la web y cómo interpretar sus datos.

      
Objetivo

      
Ofrecer una lectura práctica de las condiciones de propagación HF y de las fuentes que las respaldan.

      
Cómo leer el informe

      
    
        
  1. Comprueba la fecha y la antigüedad de los datos.
    2. 
        
  2. Revisa primero la recomendación operativa.
    3. 
        
  3. Consulta las fuentes y sus limitaciones antes de interpretar una predicción como confirmación.
    4. 
        
  4. Contrasta siempre la recomendación con actividad real, balizas, waterfall o reportes recientes.
    5. 
      

      
Convenciones

      
    
        
  • Observado: procede de actividad registrada.
    • 
        
  • Modelado: procede de un modelo físico o meteorológico.
    • 
        
  • Inferido: combina varios indicios.
    • 
        
  • Teórico: es físicamente posible, pero no está confirmado.
    • 
      

      
Cada nueva versión debe describir aquí los cambios relevantes y mantener actualizado este apartado cuando cambie el funcionamiento de la web.
